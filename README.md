# ocrinfer

Experimental R package for statistically explicit evaluation of OCR and handwritten text recognition (HTR).

The package name `ocrinfer` is provisional. The repository is intended to develop the software and reproducibility materials for a possible **R Journal** submission.

Initial scope:

- Unicode-aware normalization;
- grapheme- and codepoint-level alignment;
- CER and WER;
- edit-operation summaries;
- tidy row-level evaluation;
- toy recognition data and tests.

Planned next steps include micro/macro aggregation, hierarchical summaries, paired system comparison, cluster bootstrap uncertainty, normalization sensitivity analysis, error profiles, and publication-oriented visualisation.
